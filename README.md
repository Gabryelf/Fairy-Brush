# Fairy Brush

Векторный графический редактор для художников. Итеративная разработка.

## Версии

- **0.0.1** — фундамент: MVC + Factory, холст, кисть с точками, панели, сохранение/загрузка проекта, экспорт PNG/SVG.

## Запуск и установка

```bash
# инициализировать npm и установить зависимости
npm init -y
npm install -D vite

```

## Скрипты

- `npm run dev` — dev-сервер
- `npm run build` — сборка в `/dist`
- `npm run preview` — предпросмотр сборки
